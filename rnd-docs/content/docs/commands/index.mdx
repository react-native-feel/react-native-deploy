## Quick reference

```text
rn-deploy setup
rn-deploy credentials {configure | status | switch <name> | logout [name]}
rn-deploy build [options]
rn-deploy submit [options]
rn-deploy infra {up | down | status | ami-list | ami-delete | update-ip}
```

## Common flags

| Flag | Applies to | Description |
| --- | --- | --- |
| `--profile <name>` | `build`, `submit` | Build/submit profile name (default `production`) |
| `--non-interactive` | `build`, `infra up/down`, `setup` | Disable prompts; fail fast on missing values |
| `--no-teardown` | `build` | Keep the EC2 instance alive after build (useful for debugging) |
| `--timeout <minutes>` | `build` | Hard timeout for the entire build (default 60) |
| `--resume` | `build` | Reconnect to an in-progress build's tmux session |

## Exit codes

| Code | Meaning |
| --- | --- |
| `0` | Success |
| `1` | Generic error (config validation, SSH failure, build failure) |
| Other | Underlying CLI/system error code propagated |

Use `DEBUG=1` for verbose logging:

```bash
DEBUG=1 rn-deploy build --profile production
```

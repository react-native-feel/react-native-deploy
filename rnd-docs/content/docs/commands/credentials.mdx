---
title: credentials
description: Manage App Store Connect API keys in the macOS keychain.
---

`rn-deploy credentials` is a thin wrapper around `asc auth`. See [Credentials](/docs/credentials) for the underlying model.

## Subcommands

```text
rn-deploy credentials configure
rn-deploy credentials status
rn-deploy credentials switch <name>
rn-deploy credentials logout [name]
```

### `configure`

Interactive prompt that stores a new ASC API key in the macOS keychain.

```bash
rn-deploy credentials configure
```

Prompts:

| Prompt | Default | Source |
| --- | --- | --- |
| Friendly name | `rn-deploy` | Any string — used to disambiguate multiple keys |
| Key ID | — | Apple App Store Connect → Users and Access → Integrations |
| Issuer ID | — | Same page, header area |
| `.p8` path | `~/.appstoreconnect/AuthKey_<keyId>.p8` | Where you saved the downloaded key |

Runs `asc auth login --name <name> --key-id … --issuer-id … --private-key … --network` under the hood. The `--network` flag does a lightweight API request to confirm the key actually works before storing it.

### `status`

Show the active profile, key ID, and resolved local `.p8` path.

```bash
rn-deploy credentials status
```

```text
ℹ Active profile: rn-deploy
ℹ Key ID:         ABCD123XYZ
ℹ Issuer ID:      01234567-89ab-cdef-0123-456789abcdef
✔ Resolution source: keychain
ℹ Local .p8 path:    /Users/you/.appstoreconnect/AuthKey_ABCD123XYZ.p8
```

If "Resolution source" reads `env` or `config`, you have credentials set in environment variables or `deploy.config.json` that are taking precedence over the keychain.

### `switch <name>`

Switch the active asc profile (multi-account support).

```bash
rn-deploy credentials switch client-acme
```

### `logout [name]`

Remove a stored profile. Omit `name` to remove the default.

```bash
rn-deploy credentials logout
rn-deploy credentials logout client-acme
```

Only the keychain entry is removed — the `.p8` file on disk stays put.

## Common patterns

<Tabs items={["First-time setup", "Multiple accounts", "CI / rotate key"]}>

```bash tab="First-time setup"
rn-deploy credentials configure
rn-deploy credentials status   # verify
```

```bash tab="Multiple accounts"
# Set up two
rn-deploy credentials configure   # name: personal
rn-deploy credentials configure   # name: client-acme

# Switch between them
rn-deploy credentials switch personal
rn-deploy build --profile production

rn-deploy credentials switch client-acme
rn-deploy build --profile production
```

```bash tab="CI / rotate key"
# Don't touch keychain on CI — use env vars (see docs/credentials)
ASC_KEY_ID=... ASC_ISSUER_ID=... ASC_PRIVATE_KEY_PATH=... \
  rn-deploy build --profile production
```

</Tabs>
